quarkus-lambda-http-archetype

Archetype of an HTTP lambda with quarkus-lambda-parent. It has no Java code: this page stands for its javadoc.

mvn archetype:generate -B -DarchetypeGroupId=com.xdyan -DarchetypeArtifactId=quarkus-lambda-http-archetype \
  -DarchetypeVersion=X.Y.Z -DgroupId=com.acme.orders -DartifactId=lambda-http-orders -DrootPath=/orders/v1

Properties: artifactId (kebab-case, also the name of the lambda), groupId (code in <groupId>.app, API in <groupId>.api), rootPath (default /api/v1), package (default the groupId).
